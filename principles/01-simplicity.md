# 원칙 1. Simplicity

> 사용자가 배우지 않아도, 설명을 읽지 않아도, 본능적으로 이해할 수 있게 만든다.

단순함은 화면을 비우거나 버튼 수를 줄이는 시각적 미니멀리즘이 아니다.
**사용자가 지불하는 비용의 총합을 낮추는 것**이다.

사용자가 화면을 보며 아래와 같은 생각을 한다면 그 화면은 단순하지 않은 것이다.

- 이 기능은 무엇인가?
- 어떤 버튼을 눌러야 하는가?
- 누르면 무슨 일이 생기는가?
- 이 용어가 무슨 뜻인가?
- 잘못 누르면 문제가 생기지 않는가?
- 왜 이 정보를 입력해야 하는가?

## 공식

```text
Simplicity = 낮은 인지 비용 + 낮은 심리 비용 + 낮은 노동 비용
```

세 비용은 독립적이지 않다. 하나를 줄이려다 다른 하나를 키울 수 있으므로 항상 합계로 판단한다.

- 입력 항목이 하나뿐이어도 질문이 모호하면 → 인지 비용 ↑
- 입력은 쉬워도 민감한 정보라면 → 심리 비용 ↑
- 설명이 쉬워도 인증을 다섯 번 해야 하면 → 노동 비용 ↑

## 1. 인지 비용 — 이해하고 판단하는 데 드는 정신적 노력

### 커지는 상황

- 처음 보는 전문 용어가 등장한다
- 한 화면에 정보가 너무 많다
- 비슷한 선택지가 여러 개 있다
- 버튼을 눌렀을 때 결과를 예측하기 어렵다
- 중요한 정보와 부가 정보의 위계가 불분명하다
- 긴 설명을 모두 읽어야 행동할 수 있다
- 이전 단계의 내용을 기억해야 다음 질문에 답할 수 있다

### 판단 기준

"설명을 자세히 제공했는가"가 아니라 **"설명을 읽지 않아도 핵심을 이해할 수 있는가"**.

### Before / After

```text
❌ 서비스 이용을 위한 개인 식별 정보 연동 절차를 진행합니다.
✅ 내 보험을 불러오려면 본인 인증이 필요해요.
```

행동(본인 인증), 이유(내 보험을 불러오려면), 결과가 한 문장 안에서 연결되어야 한다.

### 줄이는 방법

- 전문 용어 → 일상어로 바꾼다. 바꿀 수 없으면 그 자리에서 풀어 쓴다
- 한 화면 = 한 가지 목적. 목적이 둘이면 화면을 나눈다
- 정보 위계를 시각적으로 분리한다 (핵심은 크게, 부가는 접거나 작게)
- 버튼 문구만 읽어도 결과를 예측할 수 있게 쓴다

## 2. 심리 비용 — 불안, 부담, 의심, 거부감

기능이 기술적으로 쉬워도 심리 비용이 크면 사용자는 행동하지 않는다.

### 커지는 상황

- 개인정보를 요구한다
- 결제나 계약이 발생한다
- 취소하기 어려울 것 같다
- 어떤 정보가 외부에 전달되는지 모른다
- 실수하면 손해가 생길 수 있다
- 결과가 확실하지 않다
- 광고나 영업으로 이어질 것 같다
- 민감한 정보를 입력해야 한다

### 핵심 통찰

연봉 입력은 몇 초면 끝난다(노동 비용 ↓). 하지만 "왜 묻는가", "어디에 쓰이는가"에 대한
불안 때문에 심리 비용은 높을 수 있다. **입력창을 줄이는 것만으로는 단순해지지 않는다.**

### Before / After

```text
❌ 연봉을 입력하세요.

✅ 받을 수 있는 대출 조건을 정확히 비교하기 위해 필요해요.
   입력한 정보는 금융사 조회에만 사용돼요.
```

### 줄이는 방법

- 민감한 정보를 요구할 땐 **왜 필요한지 + 어디에만 쓰이는지**를 함께 쓴다
- 되돌릴 수 있는 행동이면 되돌릴 수 있다고 명시한다
- 파괴적/불가역적 행동 앞에서는 결과를 미리 알려주고 확인을 받는다
- 요금·조건·제한을 숨기지 않는다 (숨기면 심리 비용은 나중에 불신으로 돌아온다)

## 3. 노동 비용 — 입력, 탐색, 이동, 반복 조작의 양

### 커지는 상황

- 긴 양식 입력
- 여러 단계 이동
- 같은 정보 반복 입력
- 복잡한 비밀번호 조건 충족
- 파일을 직접 찾아 첨부
- 긴 목록에서 항목 탐색
- 여러 번의 인증
- 매번 동일한 설정 반복
- 불필요한 확인 버튼

### 줄이는 방법

- 시스템이 이미 아는 정보는 다시 묻지 않는다
- 합리적인 기본값을 제공한다
- 자동완성, 자동 포맷팅(전화번호 하이픈 등)을 적용한다
- 이전 입력값을 기억한다
- 중간에 이탈해도 이어서 진행할 수 있게 한다

## 없앨 수 없는 비용을 다루는 법

법적 절차, 보안 인증처럼 제거할 수 없는 비용도 있다. 이때는 아래 중 하나 이상을 한다.

1. 비용 자체를 줄인다
2. 자동화한다
3. 적절한 기본값을 제공한다
4. **사용자가 얻는 가치를 먼저 보여준다** → [03-value-first.md](03-value-first.md)
5. 왜 필요한지 설명한다
6. 진행 상황을 보여준다
7. 중간에 이탈해도 다시 이어갈 수 있게 한다
